# Annotation Guidelines

Annotators should assess the dominant intended musical affect of the complete
10-second clip rather than a single frame. Use one of the five labels in
`emotion_labels.json`, record the target BPM range when available, and write a
short text prompt describing scene dynamics and intended musical character.

Do not include names, source URLs, license tokens, or other identifying media
information in public metadata. Mark `raw_media_available` as `true` only after
redistribution rights have been verified. Ambiguous samples should be reviewed
by a second annotator; unresolved samples should be excluded from public split
metadata.
